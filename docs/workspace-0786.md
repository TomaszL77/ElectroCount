# 0.7.8.6 — miejsce do pracy

- Grupy zajmują większą część prawego panelu. Przeciągnij poziomą granicę między grupami i wykryciami, aby zmienić ich wysokość.
- Podsumowanie oznaczeń, legendy i ocen: Ustawienia → Szczegóły grupy i wyników (także ikona obok widoczności grup).
- Próg podobieństwa, próg konfliktu, odległość środków i filtry widoku: Ustawienia → Ustawienia wyszukiwania i widoku… Próg obowiązuje w następnym wyszukiwaniu. Anulowanie nie zmienia ustawień.
- Wybierz wykrycie i użyj Usuń wykrycie, Delete lub menu prawego przycisku. Element znika z listy i z rysunku; Ctrl + Z przywraca go, Ctrl + Y ponawia usunięcie. Odrzuć pozostaje osobną oceną błędnego wyniku dla uczenia.
- Shift + rolka przesuwa rysunek w poziomie; bez Shift rolka nadal przybliża i oddala.
- Przytrzymaj Q, zaznacz prostokąt i puść przycisk myszy. Możesz dodać kilka elementów podczas jednego przytrzymania Q. Puszczenie Q przywraca poprzednie narzędzie. Przy przejściu do innego okna skrót jest zwalniany. Q podczas wpisywania tekstu działa jak zwykła litera.

Rozpakuj do nowego folderu, zamknij poprzednią wersję i uruchom Uruchom.cmd. W tytule: 0.7.8.6. Projekty i zainstalowany model nadal działają.

Kontrola: celowy przebieg GUI w Qt offscreen na Linux: regulacja paneli, usuwanie ręcznego / automatycznego / nieprzypisanego wykrycia i zapis projektu, cofanie / ponawianie, przytrzymanie Q dla dwóch zaznaczeń i przywrócenie poprzedniego narzędzia, ochrona wpisywania tekstu i utraty aktywności, Shift + rolka w obie strony bez zoomu, akceptowanie / anulowanie ustawień. Nie sprawdzano instalacji Windows ani nowych wyników detekcji — logika analizy pozostała taka jak w 0.7.8.5.
